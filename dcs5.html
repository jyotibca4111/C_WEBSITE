Enter a number from the user and check it is a decimal number or not ?

#include <stdio.h>
int main() {
char n[20];
int i, p=0;
printf("Enter a number: ");
scanf("%s", n);
for(i=0; n[i]!='\0'; i++) {
if(n[i]=='.') {
p=1;
break;
}
}
if(p==1) printf("It is a Decimal number");
else printf("It is not a decimal number");
}

Output:-

Enter a number: 5
It is not a decimal number
