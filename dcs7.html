Enter a character from the user and check that it is an alphabet ?

#include <stdio.h>
int main() {
char ch;
printf("Enter a character: ");
scanf("%c",&ch);
if((ch>='a' && ch<'z')|| (ch>='A' && ch<='Z'))
printf("It is a alphabet that is %c",ch);
else
printf("It is not a alphabet");
}

output:-

enter a character: A
It is a alphabet
