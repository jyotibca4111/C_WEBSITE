Enter a number from the user if the number is negative then square the number and if it is positive then increment the number 20 times ?

#include <stdio.h>
int main() {
int n;
printf("Enter the number:");
scanf("%d",&n);
if(n<0)
printf(" The number is negative ,then square of it is %d",n*n);
else
printf("The number is positive, increment 20times of it is %d",n+20);
}
