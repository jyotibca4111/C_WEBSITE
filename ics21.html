Write a program to find out the Fibonacci series/ 1 to 100 (like 0 1 1 2 3 5 8 13………..) ?

#include<stdio.h>
void main()
{
int a=0,b=1,next;
printf("Fibonacci series up to 100:\n");
while(a<=100)
{
printf("%d",a);
next=a+b;
a=b;
b=next;
}
}

Output:-

Enter number of terms:5
Fibonacci series: 0 1 1 2 3
