Enter a lower case character from user and print it into upper case ?

#include<stdio.h>
void main()
{
char ch;
printf("Enter a lower case character:");
scanf("%c",&ch);
if(ch>='a'&&ch<='z')
{
printf("Upper case character: %c\n",ch-32);
}
else
printf("Invalid input.Please enter a lowercase character.\n");
}

Output:-

enter a lower case character: a
uppercase:A
