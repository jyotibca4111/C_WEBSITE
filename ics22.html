Enter a character from user and that character should be alphabet ?

#include<stdio.h>
void main()
{
char ch;
printf("Enter a character:");
scanf("%c",&ch);
if(ch>='A'&&ch<='Z'||ch>='a'&&ch<='z')
{
printf("%c is an alphabet");
}
else
printf("not an alphabet");
}

output:-

Enter a character:A
A is a alphabet
